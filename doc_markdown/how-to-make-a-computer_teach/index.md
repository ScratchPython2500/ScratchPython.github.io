# 准备工作
准备好所需*硬件*与*工具*，并且找到*合适的地点*进行[装机](#安装)。  
[所需硬件](#硬件) | [所需工具](#工具) | [装机地点](#地点) | [返回](#)
## 硬件
中心部件：CPU、主板、内存、显卡、固态/机械  
配件：散热、电源、机箱
## 工具
普通螺丝刀（*一般情况下普通螺丝刀已经够用了*）  
小螺丝刀（*一般买相关硬件会送，如果没有相关硬件也可以不要*）
## 地点
推荐在一个***平坦的**地方*，如*盒子上*或者*桌子上*。  
*如果选好地点就不要再修改位置了！！！*
